PicSift 快速开始

从电商商品页筛选、预览并批量保存图片和直链视频。

安装

  1. 从 GitHub Release 下载并解压 PicSift-v0.0.5.zip。
  2. 打开 chrome://extensions/。
  3. 启用开发者模式，点击“加载已解压的扩展程序”。
  4. 选择包含 manifest.json 的目录。

提取与下载

  1. 打开受支持的商品详情页，等待图片加载。
  2. 点击 PicSift 图标打开全屏工作台。
  3. 设置最小尺寸和图片比例，点击“提取本页图片”。
  4. 单击选择、双击预览；选择多张图片后点击“打包下载”。

更新后没有变化？

扩展源码不会自动热更新。请在扩展管理页点击 PicSift 卡片上的“重新加载”，然后刷新工作台。
